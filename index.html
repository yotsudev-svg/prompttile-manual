Official Documentation

PromptTile 公式ドキュメント・利用マニュアル

日本語で単語を選びながら、画像生成AI向けの英語プロンプトを直感的に組み立てるためのガイドです。

対象：画像生成AIの初心者〜中級者 ／ PixAIを中心に利用する方

PromptTile は、日本語で単語を選びながら、画像生成AIへ渡す英語プロンプトを組み立てるためのWebアプリです。

1. PromptTileとは？

PromptTileは、英語タグを一語ずつ暗記しなくても、日本語で意味を確認しながらプロンプトを組み立てられるアプリです。単語タイルには英語のプロンプトと日本語ラベルが表示されるため、「何を指定しているのか」を理解しながら選択できます。選んだ順番はワークスペースに並び、最終的な英語プロンプトは自動でカンマ区切りのテキストとしてプレビューされます。

画像生成AIでは、一般に 1girl、cinematic lighting、masterpiece のような英単語やフレーズを組み合わせて、人物・構図・雰囲気・品質などを指定します。PromptTileでは、これらを日本語のカテゴリや検索から選び、必要に応じて並び替え・強調・装飾してからコピーできます。

できること概要
日本語ベースの単語選択カテゴリや日本語ラベルを手掛かりに、英語プロンプトを追加します。
ポジティブ／ネガティブの分離描きたい要素と、避けたい要素を別々に構築できます。
プロンプトの自動整形選んだタイルを、画像生成AIに貼り付けやすい文字列へ整形します。
重み・トッピング特定の要素を強めたり、色・品質・スタイルなどの修飾を付けたりできます。
保存・復元作成途中のプロンプト、保存済みセット、コピー履歴を再利用できます。
はじめて使う方へまずは「日本語で探す → タイルを選ぶ → コピーする」の3ステップだけで十分です。重みや特殊構文は、慣れてから少しずつ使うと効果が分かりやすくなります。

2. 基本操作ガイド

2.1 画面の見方

PC幅の画面では、主に左・中央・右の3エリアで構成されます。画面幅が小さいスマートフォンやタブレットでは、同じ機能が縦方向・シート形式に再配置されます。

エリア主な役割まず使う操作
左：カテゴリ大分類・子カテゴリを切り替えます。作りたい要素のジャンルを選びます。
中央：ワークスペース選択済みタイル、完成プロンプト、検索、単語一覧を扱います。タイルの追加、編集、並び替え、コピーを行います。
右：ライブラリグループ、保存済みプロンプト、コピー履歴を再利用します。過去の内容を追加・復元します。

2.2 ポジティブとネガティブを切り替える

ワークスペース上部の 「ポジティブ」 と 「ネガティブ」 を切り替えて編集します。ポジティブには「描きたいもの」、ネガティブには「避けたいもの」を入れます。両者は別々に保存・編集されるため、ポジティブを組み立てた後にネガティブへ切り替えても内容は残ります。

入力欄目的例
ポジティブ生成したい人物・服装・背景・画風・光などを指定します。1girl, cinematic lighting, masterpiece
ネガティブ生成結果から避けたい特徴を指定します。lowres, blurry, text

2.3 カテゴリから単語を選ぶ

左側のカテゴリで大分類を選び、続いて必要に応じて子カテゴリを選びます。中央下部の単語グリッドには、選択中のカテゴリに属するタイルが表示されます。各タイルには英語プロンプトと日本語ラベルが並ぶため、英語を覚えていなくても意味を確認できます。

  1. ポジティブ または ネガティブ を選びます。
  2. 左側で大分類、続いて子カテゴリを選びます。
  3. 単語グリッドから、追加したいタイルの本文部分をクリックまたはタップします。
  4. タイルはワークスペースへ追加され、プレビューに英語プロンプトが反映されます。
  5. 同じ単語をもう一度選ぶと、その単語は選択解除されます。すでに同じ英単語がある場合は、重複追加を防ぐ動作になります。

2.4 日本語で単語を検索する

中央の検索欄 「単語を検索…」 に、知りたい意味を日本語で入力します。検索は英語プロンプトと日本語ラベルの両方を対象に行われます。そのため、英語タグを知らない場合でも、たとえば「映画」「光」「青」「笑顔」のような日本語から候補を探せます。

検索のコツ具体的な単語が見つからないときは、より短い言葉にしてみてください。たとえば「映画のような光」ではなく「映画」や「光」、「夜の街」ではなく「夜」「街」のように分けて検索すると候補を確認しやすくなります。

2.5 タイルを並び替える・削除する

ワークスペースに入れたタイルは、長押ししてドラッグすることで順番を変更できます。最終プロンプトはワークスペースの順序で出力されるため、関連する要素をまとめたい場合や、読みやすく整理したい場合に便利です。

削除は、ツールバーの削除モードをオンにしてタイル内の × を選ぶ方法が基本です。各タイルを開く編集画面から 「削除」 を選ぶこともできます。PCでは、ワークスペース上の通常タイルを右クリックして削除する操作にも対応しています。

2.6 プロンプトを確認してコピーする

選択済みタイルの下には、完成した英語プロンプトを表示するプレビューがあります。タイルは通常、カンマと半角スペースでつながれます。PCではプレビュー右側のコピーアイコン、モバイルではツールバーの 「コピー」 を使うと、現在のポジティブまたはネガティブのプロンプトをクリップボードへコピーできます。

コピー前の確認ポジティブとネガティブは別々にコピーします。PixAI側にもポジティブ用・ネガティブ用の欄がある場合は、それぞれ対応するPromptTileのタブを開いてコピーしてください。

3. PixAI向けの応用機能

3.1 重み調整：特定の単語を強める・弱める

重み（Weight） は、特定の単語をどの程度強く扱うかを明示するための数値です。ワークスペース上の通常タイルをクリックまたはタップすると、タイルの調整画面が開きます。ここにある 「強調度（Weight）」 のスライダー、または増減ボタンで、0.50 から 1.50 まで 0.05 刻みで調整できます。

重み目的出力例
1.0通常の強さです。PromptTileでは重み記法を付けずに出力します。masterpiece
1.2少し強めたいときに使います。(masterpiece:1.2)
1.3以上かなり強く指定したいときに使います。まずは少しずつ上げてください。(cinematic lighting:1.3)
0.8出現を弱めたいときに使います。(smile:0.8)

たとえば、品質を少し強くしたい場合は masterpiece のタイルを開いて 1.20 にします。プレビューは (masterpiece:1.2) になります。数値を 1.0 に戻すと、括弧と数値は自動的に外れ、通常の masterpiece に戻ります。

使い方の目安最初から多くのタイルを強くしすぎると、どの指定を優先させたいのか分かりにくくなります。まずは重要な要素を1～2個だけ 1.1～1.2 にして、生成結果を比較する方法がおすすめです。

3.2 トッピング機能：単語に装飾を加える

トッピング は、対象の単語に紐づいた品質・スタイル・色などの修飾候補を、日本語で選んで追加する機能です。トッピングに対応した単語タイルには、本文部分とは別に設定アイコンが表示されます。本文を選ぶと単語をそのまま追加し、設定アイコンを選ぶとトッピング選択画面を開けます。

トッピングの候補は、すべての単語で共通ではありません。単語やカテゴリに設定されている修飾グループだけが表示されます。たとえば色を受け取るテンプレート型の単語では、選んだ色が {colorA} や {colorB} の位置に埋め込まれ、選択内容を含む英語プロンプトが出力されます。前に置く修飾と後ろに付ける修飾も、設定された順序で自動的に組み立てられます。

操作結果
タイル本文を選ぶ装飾なしの単語をワークスペースへ追加します。
設定アイコンを選ぶその単語で利用できるトッピングを日本語で選択できます。
ワークスペース上のタイルを開く重みとトッピングを後から調整できます。
各トッピングの「なし」を選ぶそのグループの装飾を解除できます。

3.3 BREAK構文：プロンプトを区切る

BREAK は、プロンプトの途中に区切りを置く特殊構文です。PromptTileでターゲット画像生成AIを 「PixAI（BREAK対応）」 にしている場合、ツールバーに 「+ BREAK」 が表示されます。追加したBREAKは通常のタイルと同じようにドラッグで移動でき、最終文字列では前後を半角スペースで区切って出力されます。

1girl, cyberpunk city, cinematic lighting BREAK (masterpiece:1.2)

上の例では、人物・背景・照明をひとまとまりにし、その後に品質指定を置いています。BREAKを使う目的は、長いプロンプトを意味のまとまりごとに整理することです。まずは「人物・外見」「背景・雰囲気」「品質・画風」のように、1か所だけ区切るところから試してください。

注意BREAKの解釈は画像生成サービスやモデル設定によって異なる場合があります。PromptTileではPixAI向けにBREAKを追加できますが、生成結果の変化はPixAI側のモデル・設定にも左右されます。PixAI以外へ貼り付ける場合は、そのサービスでBREAKが使えるか確認してください。

4. 高度な特殊構文

高度な特殊構文は、主に 「SD WebUI（A1111）」 向けの機能です。PromptTileの設定でターゲット画像生成AIをA1111に切り替えると、ANDと構文結合が使えるようになります。一方、PixAI向け設定ではBREAKを中心に使う設計です。

構文出力形式使い方の概要PixAI向け設定での扱い
BREAKA BREAK Bプロンプトを区切ります。利用できます。
ANDA AND B複数の条件をANDで結びます。通常は表示されません。
ステップ切り替え[from:to:ratio]生成途中で単語を切り替えるための構文です。通常は表示されません。
交互構文[word1|word2]2語を交互に扱うための構文です。通常は表示されません。

A1111モードでは、ツールバーの 構文結合 からワークスペース内の通常タイルを2つ選びます。結合タイプを 「ステップ切り替え」 にすると [from:to:ratio]、「交互構文」 にすると [word1|word2] が生成されます。

[day:night:0.5]
[red dress|blue dress]

ステップ切り替えでは、切り替えタイミングを 0%～100% のスライダーで指定できます。PromptTileの画面では、通常は 30%～70% 程度を使う案内になっています。PixAIを主に使う場合は、まずBREAKと重み調整を使い、これらの構文は必要になったときだけA1111モードで試すとよいでしょう。

5. 便利な機能

5.1 コピー履歴から復元する

PromptTileでは、プロンプトをコピーした時点で、ポジティブ・ネガティブの内容がコピー履歴へ保存されます。PCでは右側ライブラリの 「コピー履歴」、モバイルではライブラリシートから履歴を開きます。履歴を選ぶと、内容を確認したうえで次のどちらかを選べます。

操作内容
現在に追加今のワークスペースを残し、履歴の単語を追加します。重複した英単語は追加されません。
置き換える現在のポジティブ・ネガティブを、履歴の内容で置き換えます。

5.2 プロンプトを保存して再利用する

ワークスペース上部の保存ボタンから、現在のポジティブ・ネガティブを名前付きで保存できます。保存した内容は、右側ライブラリの 「保存済みプロンプト」 に表示されます。ライブラリ内では、以下のように必要な部分だけを読み込めます。

ボタン読み込む内容
+ポジ保存済みプロンプトのポジティブ部分を現在のポジティブへ追加します。
+ネガ保存済みプロンプトのネガティブ部分を現在のネガティブへ追加します。
一括ポジティブ・ネガティブの両方をまとめて読み込みます。

5.3 グループでパーツをまとめる

複数のタイルをひとまとめにしたい場合は、新規グループ または複数選択モードを使います。グループには名前を付けられ、グループ内のタイルを編集したり、グループそのものをライブラリへ保存したりできます。

グループ化は、毎回使う要素のセットに向いています。たとえば「人物の基本セット」「夜景背景セット」「品質セット」のようにまとめておくと、必要なときに一括で読み込めます。

5.4 NSFW表示を切り替える

成人向け（NSFW）カテゴリ・単語を表示する機能は、初期状態では有効ではありません。利用する場合は、メニューから 「設定」 を開き、「データ管理と制限」 内の 「成人向け（NSFW）コンテンツ」 をオンにして、確認画面で有効化します。

有効化後は、メイン画面で通常表示と成人向け表示を切り替えられます。通常表示では通常用データのみ、成人向け表示では成人向けデータのみが表示されるため、カテゴリや検索結果が混在しない設計です。年齢制限のあるコンテンツを扱う場合は、利用するサービスの規約と法律を確認してください。

5.5 そのほかの時短機能

機能使いどころ

クリップボードからインポートすでに持っているカンマ区切りの英語プロンプトを取り込み、タイルとして編集したいときに使います。BREAK・ANDも単独語として認識されます。
お気に入り単語タイルを長押しすると、お気に入りの切り替えができます。お気に入りはカテゴリ・検索結果の上位に表示されます。

6. 実践例

ここでは、映画のワンシーンのような、夜のサイバーパンク都市を背景にした人物イラストを作るための考え方を例にします。実際に表示される単語や日本語ラベルは、選択中の辞書によって異なるため、近い意味のタイルを選んでください。

6.1 ポジティブを組み立てる

  1. ポジティブタブで、人物カテゴリから 1girl のような主役タイルを選びます。
  2. 背景・雰囲気に関するカテゴリまたは日本語検索から、都市・夜・サイバーパンクに近いタイルを追加します。
  3. 検索欄に「映画」または「光」と入力し、cinematic lighting に近い照明タイルを追加します。
  4. 品質に関する masterpiece を追加し、タイルを開いて重みを 1.2 にします。
  5. PixAIモードなら、必要に応じて人物・背景の後にBREAKを置き、品質指定を後ろへまとめます。
1girl, cyberpunk city, cinematic lighting BREAK (masterpiece:1.2)

6.2 ネガティブを組み立てる

ネガティブタブへ切り替え、「低解像度」「ぼやけ」「文字」など、避けたい要素を日本語検索で探して追加します。

lowres, blurry, text

6.3 コピーしてPixAIへ貼り付ける

ポジティブタブでコピーし、PixAIのポジティブプロンプト欄へ貼り付けます。次にネガティブタブへ切り替え、ネガティブプロンプト欄へ貼り付けます。生成後は、一度に多くの要素を変更せず、たとえば重みだけを 1.2 から 1.1 に変える、または照明タイルだけを差し替えるというように、1回に1～2点ずつ試すと結果の違いを把握しやすくなります。

7. 困ったとき

状況確認すること
日本語で検索しても見つからない短い言葉にして再検索してください。現在の辞書が「標準辞書」か「ユーザー辞書」かも設定で確認します。
単語を追加したのに見当たらないポジティブ／ネガティブのどちらを編集中か確認してください。同じ単語は重複追加されません。
トッピングの設定アイコンがないその単語にはトッピンググループが割り当てられていない可能性があります。本文を選んで通常追加してください。
BREAKボタンが表示されない設定の「ターゲット画像生成AI」が「標準（特殊構文なし）」になっていないか確認し、PixAI（BREAK対応）を選びます。
コピーできないワークスペースに少なくとも1つ単語を追加してからコピーしてください。ブラウザのクリップボード権限も確認します。
成人向けの候補が表示されない設定でNSFW表示を有効にし、メイン画面で成人向け表示へ切り替えてください。
